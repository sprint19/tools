HSTS Builder

Generate a deterministic Strict-Transport-Security header from max-age and directive flags. No network requests.

Required integer between 0 and 2147483647.

Generated locally in your browser.

Built by Sprint19. Product engineering for startups.

This tool generates HSTS header values only. It does not verify browser preload status or live server configuration.
